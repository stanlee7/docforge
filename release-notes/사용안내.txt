================================================
  DocForge v1.0.0
  엑셀 명단 → 개인별 AI 문서 일괄 생성 (온디바이스)
================================================

엑셀에 이름·직무·성과만 채워 넣으면, AI가 행마다 완성된 문서를
작성해 개인별 파일(docx)로 만들어 줍니다.
단순 빈칸 채우기가 아니라, 데이터를 근거로 한 'AI 작문'입니다.
모든 처리는 내 PC 안에서 끝납니다. 데이터가 외부로 나가지 않습니다.

------------------------------------------------
[ 처음 한 번만: 환경 준비 ]
------------------------------------------------
이 프로그램은 PC 안에서 도는 AI 모델(구글 젬마)을 사용합니다.
DocForge.exe 를 처음 실행하면 '환경 준비' 창이 자동으로 뜹니다.
  → [자동 준비 시작] 한 번만 누르세요.
  → AI 실행기(Ollama) 설치 + 모델 다운로드(약 4GB)를 알아서 합니다.
  → 인터넷이 필요한 건 이 최초 1회뿐입니다. 이후엔 오프라인 동작.

* '문서 배치(DocBatch)'를 이미 쓰고 있다면 같은 AI 모델을 공유하므로
  추가 다운로드 없이 바로 사용할 수 있습니다.

------------------------------------------------
[ 사용법 ]
------------------------------------------------
1. DocForge.exe 실행
2. [찾아보기]로 명단 엑셀(.xlsx) 선택 (첫 행 = 컬럼 이름)
3. 문서 유형 / AI에 넣을 컬럼 / 작성 지침 / 파일명 패턴 지정
4. [1행 미리 생성]으로 결과 품질을 먼저 확인
5. [일괄 생성 실행] → 끝나면 [출력 폴더 열기]

옵션
  · 빠른 모드  : 더 빠르지만 품질이 낮은 경량 모델(1b). 기본은 4b.
  · 출력 형식  : docx(기본) / txt / md
  · 파일명 패턴: 예) {이름}_성과평가서  →  홍길동_성과평가서.docx

엑셀 예시 (첫 행은 컬럼명)
  이름 | 직무 | 성과 | 평가지표
  홍길동 | 백엔드 개발 | 장애율 40% 감소 | 목표달성 110%

------------------------------------------------
[ 요구사항 ]
------------------------------------------------
· Windows 10 / 11 (64bit)
· RAM 8GB 이상 권장
· 출력 docx/txt/md는 워드·한글 등 어디서나 열림 (별도 프로그램 불필요)

------------------------------------------------
[ 안내 ]
------------------------------------------------
· "알 수 없는 게시자" 경고: 코드 서명이 없는 새 프로그램의 일반적인
